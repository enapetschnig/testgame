🛣️ Google Street View verbinden (nicht verbunden)

Mit einem eigenen Google-Maps-API-Key fährst du im echten Street-View-Panorama und die Häuser bekommen ihre echten Fassaden als Textur. Der Key bleibt nur in deinem Browser (localStorage) und wird an niemanden gesendet außer an Google selbst.

Key erstellen: Google Cloud Console → APIs & Services → Credentials. Benötigte APIs: Maps JavaScript API, Street View Static API. Ohne Key läuft alles trotzdem — dann in stilisierter Steiermark-Optik.
